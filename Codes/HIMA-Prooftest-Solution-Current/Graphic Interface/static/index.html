Service & SILworX advanced

Prooftest service

Start runs the Prooftest engine (OPC poll and sync). Stop ends the engine only — this web page stays open so you can Start again. Mutating actions require a localhost browser session.

SILworX attach

Connect and Disconnect attach or detach this tool’s SILworX API/plugin only — they do not open, close, or quit the engineer’s SILworX project, and do not kill c3.exe.

Advanced SILworX

Use Release only when uninstalling SILworX. Re-integrate after reinstall. Prefer Connect/Disconnect for normal use.
