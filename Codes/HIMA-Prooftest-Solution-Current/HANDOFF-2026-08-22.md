## 11. Freeze-at-test-end sequence (reference)

```
Poll thread on .Running fall:
  1. READ OPC members once (read-only)
  2. INSERT frozen copy into ProofTest_* SQL immediately
  3. Enqueue job { snapshot, record_id, snapshot_table }

Report worker (when free):
  1. Build HTML/PDF from frozen snapshot (no OPC re-read)
  2. UPDATE ReportPath on existing SQL row by record_id
```

**Hard constraint:** Tool only reads OPC — never writes/forces/clears OPC tags.
